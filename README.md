# linden-engine-flappy-flight

FlappyFlight — a Flappy Bird style game built with **Linden Engine** (ECS + Three.js/WebGPU + Rapier physics).

> Dibuat dengan [Linden Engine](https://lindenengine.com) — © 2026 AlStartlight

## Project structure

- `project.linden.json` — project configuration, input actions, scenes in build
- `scenes/Main.lscene` — main game scene
- `scripts/FlappyGame.ts` — gameplay script (score, obstacles, game over)
- `ui/hud.html` — HUD overlay
- `assets/` — textures, audio, and models

## Play

Open the project in Linden Engine and press Play, or export a web build
(`export_web`) to produce a playable HTML5 distribution in `build/`.
